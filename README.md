# Lond — Nona Birthday ☕✨

An interactive Coffee & Cream birthday website for لوند (Nona).

Birthday countdown: 20 October 2026, 00:00 (Asia/Riyadh).

## GitHub Pages

Publish from `main` / `/ (root)` in Settings → Pages. Expected address: https://murtadhah.github.io/Lond/

**Important:** GitHub Pages is static; the public page source cannot keep the birthday greeting secret before midnight. The countdown is a visual gate, not server-side security.

Audio is optional and starts on user interaction. Photo placeholders require images to be supplied and uploaded separately.
