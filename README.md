# Lond — Nona Birthday ☕✨

Personal gift for لوند (Nona), with Coffee & Cream visuals, optional synthesized music, coffee interaction, programmer easter eggs, and an opening countdown to **2026-10-20 00:00 Asia/Riyadh**.

## GitHub Pages

The contents of this folder should be at the **root** of the `Lond` repository. In GitHub choose **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Once GitHub Pages deployment finishes, visit `https://murtadhah.github.io/Lond/`.

## Privacy limitation (important)

This is a **static GitHub Pages build**. JavaScript changes the visible page at midnight, and checks the GitHub Pages HTTP Date header when available, but the encrypted-looking Base64 celebration payload is embedded in the public HTML and can be decoded before midnight. It is **not a secure time lock**. A determined visitor can inspect the source. For a real server-side lock, use the separate Cloudflare Worker build from the original `nona-birthday-ready.zip` and keep the greeting source in a private repository until release.
